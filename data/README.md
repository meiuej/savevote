# Данные Умного голосования — 2026

`umg-2026.json` получен только из листа «Кандидаты» файла
`GOSDUMA-2026-UMG.xlsx`. Ключ — номер одномандатного округа.
Контрольная сумма исходного XLSX и число записей — в `umg-2026-source.json`.

Для обновления установите Python и `openpyxl`, затем из корня проекта выполните:

```sh
python3 scripts/import-umg.py /path/to/GOSDUMA-2026-UMG.xlsx
```

Импорт проверяет заголовки, обязательные поля и уникальность номеров;
при ошибке не перезаписывает данные. Текст сохраняется без исправлений.
Пустая партия хранится как `null`; фраза источника «Мы не смогли определить
кандидата» сохраняется дословно.

Сайт загружает JSON по HTTP. Для локального просмотра запустите
`python3 -m http.server 8000` из корня проекта и откройте
`http://localhost:8000/#umg`. При открытии HTML через `file://` загружается
`umg-2026-local.js`, который импортёр создаёт из тех же данных одновременно
с JSON. Этот файл не редактируется вручную и не загружается на HTTP-сайте.

Поиск использует только целый положительный номер округа. Ввод региона,
партии или адреса не запускает подбор кандидата. Если номера нет в JSON,
показывается сообщение об отсутствии данных; ошибка загрузки отображается отдельно.
